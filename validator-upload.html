🔒 File Anda tidak pernah dikirim ke server — parsing (.docx via Mammoth.js) dan seluruh analisis sitasi berjalan langsung di browser Anda. Pratinjau & PDF juga dibuat di sisi klien menggunakan fitur cetak bawaan browser (tanpa library tambahan yang berat). Maksimum ukuran file 25MB; untuk naskah besar, proses analisis dijalankan di background (Web Worker) supaya tab browser tidak macet.

✅ Khusus untuk file .docx: sistem otomatis mengecek format italic (nama jurnal/judul buku) dan huruf besar-kecil judul (sentence case vs Title Case) — dibaca langsung dari format asli file Word, bukan dari copy-paste, jadi hasilnya akurat. Muncul di tab "Saran" setelah proses selesai.
🎓 Cek Status Scopus (opsional — butuh data Scopus Source List)

Cocokkan referensi Anda terhadap daftar sumber Scopus resmi (Elsevier), diproses sepenuhnya di browser Anda — berkasnya tidak diunggah ke mana pun. Kalau scopus_sources.json (dan opsional scopus_proceedings.json) sudah ditaruh sejajar dengan engine.js di repo GitHub Anda, keduanya termuat otomatis tiap halaman dibuka — tidak perlu upload manual. Kalau belum ada di repo, unggah manual lewat kolom di bawah sebagai alternatif. Setelah data tersedia (otomatis atau manual), pengecekan referensi juga berjalan otomatis begitu Anda menjalankan proses di atas — tidak perlu klik tombol apa pun, hasilnya langsung muncul di tab "Scopus" & laporan PDF.
